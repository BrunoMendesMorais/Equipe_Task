# Projeto I Programação para Web
Bruno Mendes| Claudionor Cosme| Guilherme Brito | Lucas Rafael | Marcelo Henrique

Objetivo Desenvolver uma aplicação em VUE de gerenciamento de task.

O sistema deve permitir o gerenciamento de tasks e usuarios, consumindo uma API REST.


## Tipos de Commits
- 🟢 **Feat:** Adicionando um novo recurso ao projeto.
- 🔴 **Fix:** Corrigindo um erro ou bug.
- 🔵 **Docs:** Alterando apenas a documentação.
- 🟡 **refactor:** Refatorando o código.
- 🟣 **style:** Alterando a formatação.
